Connect Four

What a neural network learns about a game it was never taught to play

Download the report (PDF)

What the project is about

Given a Connect Four position, can a model predict who wins? Not by searching the game tree — by learning from thousands of finished games what a winning board looks like.

The dataset is a set of board positions, each labelled with the eventual outcome: red wins, yellow wins, or draw. The first thing worth noticing is that the labels are badly unbalanced — around 66% red, 23% yellow, 10% draw — which means any model will be biased towards predicting a red win. That bias had to be accounted for rather than ignored.

The model

  • 42input neurons — one per cell of the 7×6 grid
  • 2 × 31hidden layers with ReLU activation
  • 89%accuracy on the training set
  • 82%accuracy on the held-out test set

A Multi-Layer Perceptron, trained with the Adam optimiser and early stopping. The gap between training and test accuracy is small — the model generalises rather than memorising, even if 82% is modest by modern standards.

The interesting part is not the accuracy. It is that the weights the network learned can be read back: laid out over the board, they show which squares the model came to consider important — and it converged on something Connect Four players already know.

Where would you open?

Pick a column for the first move and see what the network thinks of it. The values are the weights the model learned for the bottom row — the squares where a first piece actually lands.

These are raw model weights read from the trained network, not measured win probabilities. Zero means neutral; the sign tells you whether the model associates that square with winning or losing positions.

What it learned

The network was never told the rules. It never searched ahead. It only saw finished boards and their outcomes — and from that alone it concluded that the centre columns matter most and the far right column is a liability.

That happens to be correct: Connect Four is a solved game, and the first player wins with perfect play only by opening in the centre. The model rediscovered a piece of game theory from data, which is a good illustration of what these methods do — and of why reading a model's weights is worth the effort, rather than stopping at its accuracy score.
